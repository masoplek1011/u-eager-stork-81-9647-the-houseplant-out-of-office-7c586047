A one-line out-of-office auto-reply written as if by a houseplant: the fern, ignored for 214 days without water, has filed a formal grievance — and your email is exhibit #47. One fixed, deterministic line, at most 120 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the entry to `/tmp/out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
